git --version
I ran this to check that Git 2.49.0 is installed and working on my Windows PC.

git config --global user.name / user.email
I used these to tell Git that the commits are mine: Akhila Sirumalle, akhilasirumalle@gmail.com.

git init
I used this in my RecipeBox folder to start tracking it as a Git repository.

git branch -M main
I ran this so my main branch is named main.

git add
Before every commit I used this to pick the files to save (index.html, about.html, .gitignore, demo.txt, git_commands.txt).

git commit -m
This saves the staged files as a snapshot with a message. My first message was "Create RecipeBox home and about pages".

git branch feature
This creates a new line of work called feature, separate from main.

git switch feature / git switch main
I used these to move between the feature and main branches and change the files in my folder to match each one.

git merge --no-ff
I used this to bring the feature branch into main, and --no-ff makes sure a merge commit is always created (9c20aca).

git log --oneline --graph --decorate --all
This shows the history of all branches as a graph, including where feature split from main and joined back.

git log --oneline --all
This shows a short list of commit IDs and messages across all branches.

git status
I used this to see which files were modified, staged, or untracked, and whether the working tree was clean.

git status --short
This is the same as status but shows one short line per file.

git check-ignore -v
I used this to check debug.log and temp/notes.txt and see which .gitignore rules matched them (*.log and temp/).

git revert --no-edit HEAD
This undoes my last commit by adding a new commit that removes demo.txt, so the old history stays intact (4c4f498).
